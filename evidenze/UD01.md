# Evidenza — Preparazione dell'ambiente e metodo di lavoro

## Ambiente verificato

La postazione utilizza Windows con WSL 2 e una distribuzione Ubuntu supportata. I progetti sono conservati nel filesystem Linux e vengono aperti con Visual Studio Code tramite l'estensione WSL.

| Componente | Versione o stato pubblicabile | Verifica eseguita |
|---|---|---|
| WSL | 2.7.13.0 | `wsl --version` |
| Ubuntu | 24.04.4 LTS | `cat /etc/os-release` |
| Visual Studio Code | 1.136.1 | `code --version` |
| Git in Ubuntu | 2.43.0 | `git --version` |
| Azure CLI | 2.90.0 | `az version` |

## Workflow completato

Ho verificato la configurazione di WSL 2 e Ubuntu e ho creato una cartella di lavoro nel filesystem Linux.

Ho configurato Visual Studio Code per lavorare direttamente nell'ambiente Ubuntu tramite l'estensione WSL.

Successivamente ho verificato e configurato Git e ho clonato il repository del corso nella cartella di lavoro.

Ho creato inoltre un repository GitHub personale denominato `azure-devops-lab`, separato dal repository del corso, nel quale conservare laboratori ed evidenze.

Il comando `git status` è stato utilizzato per controllare i file nuovi o modificati. Con `git add` sono stati selezionati i file da includere nel commit e con `git commit` è stata registrata una nuova versione locale del lavoro. Infine, tramite `git push`, il commit è stato pubblicato sul repository personale GitHub.
